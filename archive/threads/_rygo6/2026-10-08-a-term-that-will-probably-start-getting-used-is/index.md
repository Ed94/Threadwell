A term that will probably start getting used is 'Code Laundering'.

Truth is. If you have a large complex application. You can derive subsets of it. Blending it with other things. If the code is of good quality the result can actually be very good quality. If you want an example of this. Point Astra at all of the Linux kernel drivers and have it derive a new driver for some new device. A mass pool of quality C code with every critical decision captured in the code can interpolate a new derivative of that pretty much as good as anyone could if not better.

But of course, if you just take some big commercial software and do that,and it's traceable, it's very legally complicated.

So, you have to 'Launder' the source of the weights somehow.

Feed the codebase you want to clone into Claude and OpenAI. If it's a closed source application decompile it and get it's source as fixed up as possible and start to do the same. Feed that code into all the LLMs. Post the codebase online in various places for web crawlers to find in some format and include in their training set. Somehow get it interwoven with the mass soup of training data across every companies training data.

Then at some point, completely unrelated to you, with an entirely fresh account and prompt, you could prompt "Create ____ application!" And it will. Because the source data has already deeply influenced the model. But you can say it just came from Claude!

I believe the truth is, this is already what's happening. But not intentionally by the users. The reason an LLM can one-shot so many things is because something similar was in source training data, by some game of telephone. Where did it come from? Who knows. Anthropic probably stole a bunch of data from somewhere. Then paid the lawyer fees to suppress it and won. Then some open model stole Anthropic's weights and probably stole the weights and data from many other sources. Then Anthropic stole the weights back from that open model. It starts to become impossible to track down what anything came from.

It opens the door where if you can get some application's source code, original or decompiled, heavily exposed to all the LLMs in some manner. Then it all goes into a soup of weights. Then with the right prompts it could draw out derivatives of that application.

Of course, this is crazy controversial. But this is what's going to end up happening irrelevant of anyone's opinion on it. I believe it already is happening whether people know it or not. 

So why not seed it with what you want? Decompile all the applications you'd ever want to recreate. Prompt claude, openai, whatever to digest them. Influence the soup of training data with what you want.
