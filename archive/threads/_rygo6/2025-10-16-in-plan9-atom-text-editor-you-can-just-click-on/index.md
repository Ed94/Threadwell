In plan9 atom text editor you can just click on any chunk of text that happens to be a terminal command and that will then run in the terminal, and either echo back to the terminal, or echo back to the source document, or to a new document, to easily save the results depending on a which token you prepend to the command.

So then selectively running a series of commands for something is just a matter of opening a text file and clicking down which ones you want. 

Or to re-run a command on a chunk of text in the file it's just a matter of selecting the text to process, then clicking the command. Which the command could just be in the comment block of the source code.

It amazes still to this day there is nothing like this on another OS... was seriously a wtf moment for how many years I've spent manually copying and pasting things to the terminal to run. 

I guess maybe jupyter notebooks are in a similar direction but not really. 

I am also oddly realizing this is the simplest way to get some more automated interfacing with claude CLI and keep track of prompts you use. 

Was all just built into plan9 but it's a UX pattern that few ever familiarized themselves with so it never got replicated.
