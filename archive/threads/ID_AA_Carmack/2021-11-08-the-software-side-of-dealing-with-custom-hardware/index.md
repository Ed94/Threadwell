The software side of dealing with custom hardware is unpleasant, and a drain on building it and exploiting it when completed. I suspect there would be a useful boost in innovation if there was a library that made it trivial to write one-page C and Python programs that could do \

**2/** **@ID_AA_Carmack** ^1457779240980520963

high performance interfacing with arbitrary USB and PCIe hardware.  You can obviously get it done with existing interfaces, but it isn't fun, and the loss due to friction in a many-user world is often surprisingly large.
