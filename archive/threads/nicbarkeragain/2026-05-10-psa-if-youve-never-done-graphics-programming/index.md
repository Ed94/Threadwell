PSA: if you've never done graphics programming before and are interested in learning the fundamentals, it is very important that you don't start with Vulkan. You might get the impression that it's the "correct" or "modern" way to do things, but it will only bring you sorrow.

**2/** **@nicbarkeragain** ^2053297529543090391

Best place to start is a couple layers up where you still need to deal with fundamental principles (basic 3d math, loading geometry & textures, shaders). E.g. raylib, SDL, sokol. If you want to go lower, despite what you've read, OpenGL is actually totally fine for beginners.
