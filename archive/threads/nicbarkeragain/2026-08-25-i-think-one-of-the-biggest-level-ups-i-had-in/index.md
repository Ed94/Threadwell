I think one of the biggest level ups I had in programming was shaking off the metaphor associated with data "moving". There's no such thing as moving bits, you can only copy them from one place to another. You can't "remove" array / list elements, you can only overwrite them.

Computers don't work at all like the physical world. We tend to mentally conceptualize a computer like a factory floor with things moving from one place to another, but a running program is much more like a painting. To "move" something you need to cover and repaint it elsewhere.

**3/** **@nicbarkeragain** ^2092392060280307994

It's so easy as a student / junior to think of a list type structure as being "empty". When in reality you're using the length / count to represent emptiness, the element memory is still there regardless (maybe zeroed, maybe not)
