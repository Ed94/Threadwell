i'm branch-free by default. it's not for conventional optimizations (e.g. optimizing for time), but to maintain a minimum code depth / reduce complexity.

my paradigm also dislikes branches. i only want A->B, and not A->{B|C|D}. essentially, the more possibilities A can transform into -> more branches -> more complex.
