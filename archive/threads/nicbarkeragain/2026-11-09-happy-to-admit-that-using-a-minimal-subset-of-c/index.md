The main thing that feels like a significant downgrade from C99 is that designated initializers in C++ are _terrible_. Forcing the fields to be specified in order, lack of nested `.field.subField = value` style access, no [enum] = value in arrays etc really hurt the DX.

**3/** **@nicbarkeragain** ^2119934268910772471

Of course the fact that it still uses C's #include machinery is objectively terrible. By far the biggest quality of life upgrade when you switch from C/++ to something like Odin or Jai is how you compose files together IMO.
