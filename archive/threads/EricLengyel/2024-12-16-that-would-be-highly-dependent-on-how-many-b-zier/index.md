That would be highly dependent on how many Bézier curves are involved, whether you're using only fills or a mix of fills and strokes, what stroke features are used (cap, join, dashing), and how fast you're able to upload the output data to GPU-accessible memory. Keep in mind that any objects that are simply transformed without paths changing do not need to be remade when they move.
