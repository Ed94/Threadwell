Definitions we use when timing hard real-time ticks:

Jitter - Max time minus min time

Predictability - Bounded latency and jitter for a given input

Determinism - Constant latency, minimal jitter, for a given input

Isochrony - Constant latency, minimal jitter, for *any* input
