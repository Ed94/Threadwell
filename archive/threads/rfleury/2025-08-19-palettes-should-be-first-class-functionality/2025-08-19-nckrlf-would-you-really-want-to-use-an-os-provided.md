**2/** **@rfleury** ^1957865199530307770

Yes, I would, because a single interface that solves the problem is consistent & uniform across the entire system, whereas each program having bespoke ones means: (a) most programs don’t have it, (b) most programs that do have a bad implementation, (c) every program is inconsistent in their conventions. The reason I don’t use OS APIs for any UI is because it’s all thoroughly substandard.
