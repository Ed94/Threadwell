The new 4coder update, beta 4.1.0, has been awesome! I've already had a ton of fun adding custom editor features that both help out quite a bit when programming, or are just fun. Here's a thread showcasing them:

#programming

**2/** **@rfleury** ^1208980963465678848

Scope ending annotations, brace highlight, and brace lines! If the top of a scope is not visible, an annotation will be displayed at the closing brace to help me understand where I am.

![](https://pbs.twimg.com/media/EMcpxXcUYAAyrJz?format=png&name=orig)

**3/** **@rfleury** ^1208980980989456384

Code peek! I can take a look at type/function/general search results of an identifier instantly, without opening a separate tab or window.

![](https://pbs.twimg.com/media/EMcpyDIUUAAd72J?format=jpg&name=orig)

**4/** **@rfleury** ^1208980987427741696

Calculator comments! Any comment starting with '//c' will be parsed as a set of mathematical statements. Variables and functions can be used. Very useful for quick inline calculations that either document some math, or are used as rough calculations in the moment.

![](https://pbs.twimg.com/media/EMcpzE8UcAArQAk?format=png&name=orig)
